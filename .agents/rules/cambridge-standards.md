# Cambridge Primary Checkpoint Year 6 Standards

When generating content, questions, or formatting for this project:
1. **Source Material**: All questions must strictly match the style, rigor, and topic scope of official Cambridge Primary Checkpoint past papers.
2. **Format - Math**: Short-answer questions, 1-2 marks each. Never use paragraph scenarios. Focus on calculation, fractions, sequences, basic geometry, mental math.
3. **Format - Science**: Structured, multi-part questions (e.g., 1a, 1b) revolving around a single experiment, diagram, or data table. Never use general text passages. Place the scenario directly into the question text using line breaks. Do not include 'Waves' as a topic.
4. **Format - English**: Must include Reading Comprehension (with passage) and Writing (extended essay/story prompt).
5. **Difficulty Enforcement**: "Hard" questions must be exceptionally tricky, testing deep multi-step thinking, edge-cases, and common misconceptions. Distractors must be highly plausible.
